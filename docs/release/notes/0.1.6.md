Safer uninstall, install records kept per D2R folder, and fixes for stuck starts, recovery and a deleted mod folder.

## New

- The product page shows the Diablo II: Resurrected logo at the top left of the hero, with Project above it (PD2R) or 09 below it.

## Fixed

- One product's broken or too-new release no longer makes every product show offline. The others keep their updates.
- A download or catalog refresh that stalls on a dead connection now fails after a timeout instead of hanging, so Cancel, Quit and Play work again.
- An installed PD2R now has Clean install… in its ⋯ menu, so an Update that stops on a file the launcher did not install can be recovered.
- If you change the D2R location to a folder without PD2R, the launcher now offers Install there instead of Update, Repair and Uninstall.
- Install, Update and Repair no longer fail with "cannot write ... (os error 3)" when the D2R folder has no PD2Resurrected folder yet. The launcher now creates it.
- Uninstall no longer leaves a release's files behind while saying PD2R was uninstalled. Files that changed from the release now move to a backup folder next to the PD2R folder, and the result says which files stayed.
- When a newer D2RLoader is installed that the latest PD2R allows, the launcher now offers Update and the ⋯ menu instead of only asking you to get D2RLoader.
- If the game closes while starting, or a Repair didn't finish, and an update is available, Update is now offered, and the ⋯ menu is there after a startup failure.
- When a previous change didn't finish, Check again now says why it can't recover (a File Explorer window open in the folder, or the game running), and Repair and Uninstall in ⋯ are disabled until it does.
- If you delete the PD2R folder in File Explorer, the launcher now offers Repair instead of showing Ready and starting the game with no mod.
- Installing PD2R in a second D2R folder no longer makes the launcher forget the first folder's install. Switching back to it shows PD2R installed again.
